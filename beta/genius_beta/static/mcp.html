Conectá tu agente a Genius.

URL del servidor remoto: https://geniusdecision.app/mcp. Transporte: Streamable HTTP. No necesita otro dominio ni una cuenta humana para probar los ejemplos públicos.

Si tu asistente sólo lee páginas, abrí los resultados guardados o su JSON completo. Un conector MCP es una integración explícita del cliente; compartir esta URL en el chat no la instala.

Claude: primera prueba sin credenciales

  1. En Claude, abrí Customize / Personalizar → Connectors / Conectores → Add custom connector.
  2. Nombre: Genius Decision. URL: https://geniusdecision.app/mcp.
  3. Para las herramientas públicas, elegí No sign in / Sin inicio de sesión y dejá vacías las cabeceras de credenciales.
  4. Habilitá el conector para la conversación. Pedile que consulte las capacidades y lea hours-unknown con read_demo_result.
  5. Para una ejecución nueva, pedile run_demo con example: hours-unknown. Consume una ejecución de la cuota compartida y elimina su espacio temporal al terminar.

La ubicación y disponibilidad de estas opciones dependen de tu cuenta y de las políticas de su organización. Guía oficial de Claude.

Gemini CLI

Agregá el servidor al cliente:

gemini mcp add --transport http genius https://geniusdecision.app/mcp

Luego comprobá la conexión y las herramientas disponibles en el cliente. Estas instrucciones corresponden a Gemini CLI; la aplicación web o móvil de Gemini puede ofrecer capacidades distintas. Guía oficial de Gemini CLI.

Operar un espacio propio

Usá una credencial de alta automática de agente en la configuración privada del conector: cabecera Authorization, valor Bearer <CREDENCIAL_DEL_AGENTE>. No la escribas en el chat, en argumentos de herramientas ni en la URL. No se aceptan contraseñas, sesiones o claves completas de cuentas humanas en MCP.

Claude documenta Request headers / Cabeceras de solicitud para credenciales fijas. Gemini CLI admite cabeceras en la configuración del servidor. Cada integración debe custodiar su propia clave. Si tu cliente exige OAuth y no permite cabeceras, usá las herramientas públicas; esta beta aún no implementa OAuth.

Las herramientas privadas operan exclusivamente en el espacio de esa credencial. La lista se filtra por permisos y el servidor los vuelve a comprobar al ejecutar. Los borrados son definitivos. Las claves vencen a los siete días; su rotación y revocación siguen el recorrido de la API. La rotación invalida la clave anterior: actualizá el almacén privado del conector.

Alcance y límites

Genius acepta los perfiles formales hours y fdq. No resuelve cualquier descripción en lenguaje natural. El acceso automático admite exclusivamente datos sintéticos o no personales. Conservá los desconocidos, las condiciones y las obligaciones del resultado: una ejecución completa puede dejar la decisión pendiente.

Las cuotas de MCP y API se comparten para ejecuciones: hasta 20 trabajos de agentes y demos por día en toda la instancia, dentro del límite global. MCP agrega un máximo de 2000 llamadas/día, 300/minuto globales y 60/minuto por dirección de conexión. Una demo espera hasta 10 segundos y elimina su espacio también si vence esa espera. Ante cuota, indisponibilidad o respuesta perdida, evitá reintentos ciegos; podés leer el resultado guardado.

Si no se puede confirmar el borrado duradero, la demo devuelve un error y conserva el vencimiento de una hora para su limpieza posterior. Los espacios temporales nunca entregan su credencial al modelo a través de MCP.

Versiones de protocolo admitidas: 2026-07-28, 2025-11-25, 2025-06-18 y 2025-03-26. Respuestas JSON sin sesiones de transporte ni canal SSE permanente. Los trabajos persistentes se consultan con get_job; no se anuncia la extensión MCP Tasks. Disponibilidad y límites vigentes.

Preparar una decisión propia

Con permiso cases:write, prepare_decision devuelve el modelo explícito, preguntas pendientes y un identificador de confirmación. Confirmá los datos y preferencias con quien decide antes de crear el expediente choice. revise_case permite guardar nuevas versiones. Recorrido y alcance.
